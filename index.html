Ecossistema Open Source Moodle

Plugins, Ferramentas CLI & Extensões Moodle

Uma biblioteca completa de repositórios open source projetada para expandir o ecossistema Moodle: editores de texto WYSIWYG, módulos de atividades interativas, blocos visuais e utilitários CLI de alta performance para administradores.

Editores & Formatação

✍️ Editores & Formatação de Conteúdo

Plugins e utilitários de edição de texto para enriquecer a experiência de criação de conteúdos nas salas virtuais do Moodle, cobrindo os editores Atto, TinyMCE e TipTap.

📝

moodle-atto_justify

Plugin para o editor Atto nativo do Moodle que adiciona o botão de alinhamento de texto justificado na barra de ferramentas dos editores de cursos.

Moodle Atto Text Justify WYSIWYG
GitHub Documentação
✍️

moodle-tiny_justify

Plugin para o editor TinyMCE no Moodle (4.1+) que integra a opção de justificar blocos de texto diretamente na barra de ferramentas do TinyMCE.

Moodle TinyMCE Justify TinyMCE 6
GitHub Documentação
🚀

moodle-editor_tiptap

Plugin de editor WYSIWYG moderno para Moodle baseado na biblioteca TipTap, oferecendo uma experiência de edição extremamente rápida e limpa.

Moodle TipTap Editor WYSIWYG
GitHub Documentação
🛠️

moodle-local_tinytoolbar

Plugin local para configuração e personalização centralizada dos botões e disposição das ferramentas no editor TinyMCE do Moodle.

Moodle Local Plugin TinyMCE Toolbar
GitHub Documentação
Atividades Pedagogicas

🧩 Atividades Moodle

Módulos de atividades educacionais interativas integradas ao sistema de acompanhamento e conclusão de curso do Moodle.

🗺️

moodle-mod_imagemap

Módulo de atividade para criação de mapas de imagens interativos com hotspots clicáveis e suporte a exibição condicional baseada na conclusão de atividades.

Moodle Activity Mod Image Map Interactive
GitHub Documentação
Blocos & Banners

📢 Blocos Moodle

Plugins de blocos laterais e de conteúdo personalizáveis para destaque de avisos, recomendações e recursos nos cursos.

📢

moodle-block_recommendation

Plugin de bloco para exibição de recomendações personalizadas em HTML, avisos estratégicos, banners e links de destaque em áreas do Moodle.

Moodle Block Recommendation HTML Banner
GitHub Documentação
Administração & Utilitários CLI

⚙️ Ferramentas de Administração & CLI

Soluções robustas em scripts CLI e plugins de administração para automatizar backups em lote, migração de banco de dados, filtros customizados e gestão de usuários.

💾

moodle-tool_brcli

Ferramenta CLI (BrCLI) para backup e restauração em lote de categorias completas de cursos no Moodle diretamente via linha de comando.

Moodle Admin Tool CLI Backup & Restore
GitHub Documentação
👥

moodle-tool_bulkclienrolment

Utilitário de linha de comando para inscrição e matricular em massa de usuários em cursos do Moodle com automação por script.

Moodle Admin Tool CLI Bulk Enrolment
GitHub Documentação
🗄️

moodle-tool_dbmigrate

Ferramenta CLI para migração eficiente e segura de banco de dados do Moodle entre diferentes SGBDs (como de MySQL para PostgreSQL).

Moodle Admin Tool CLI DB Migrate PostgreSQL
GitHub Documentação
🔍

moodle-tool_participantscustomfilter

Plugin admin tool que adiciona suporte a filtros por campos personalizados de perfil na listagem de participantes dos cursos (/enrol/index.php).

Moodle Admin Tool Custom Filter Participants
GitHub Documentação
🎗️

moodle-tool_ribbons

Plugin de administração para identificação visual de ambientes (Desenvolvimento, Homologação e Produção) com faixas coloridas configuráveis.

Moodle Admin Tool Ribbons DevOps
GitHub Documentação
📋

moodle-profilefield_json

Plugin de campo de perfil de usuário em formato JSON, permitindo o armazenamento e visualização avançada de metadados estruturados.

Moodle Profile Field JSON User Data
GitHub Documentação
🐳

docker-compose

Modelo e orquestração Docker Compose para rápido provisionamento de ambientes de desenvolvimento local Moodle com banco de dados.

Moodle Docker Docker Compose Infra
GitHub Documentação
