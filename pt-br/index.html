Ecossistema Open Source Moodle

Plugins, Ferramentas CLI & Extensões Moodle

Uma biblioteca completa de repositórios open source projetada para expandir o ecossistema Moodle: editores de texto WYSIWYG, módulos de atividade, formatos de curso, inscrição condicional, ferramentas de administração e infraestrutura de desenvolvimento.

Moodle Plugins

🔌 Plugins Moodle

Extensões, editores de texto, módulos de atividade, formatos de curso, métodos de inscrição e ferramentas administrativas integradas ao ecossistema Moodle LMS.

Editores & Formatação

✍️ Editores & Formatação de Conteúdo

Plugins e utilitários de edição de texto para enriquecer a experiência de criação de conteúdos nas salas virtuais do Moodle, cobrindo os editores TinyMCE e TipTap.

✍️

moodle-tiny_justify

Plugin para o editor TinyMCE no Moodle (4.1+) que integra a opção de justificar blocos de texto diretamente na barra de ferramentas do TinyMCE.

TinyMCE Justify TinyMCE 6
GitHub Documentação
🔤

moodle-tiny_fontsize

Plugin para o editor TinyMCE no Moodle (4.1+) que permite selecionar e ajustar tamanhos de fonte customizados para trechos de texto formatado.

TinyMCE Font Size Tipografia TinyMCE 6
GitHub Documentação
🔠

moodle-tiny_fontfamily

Plugin para o editor TinyMCE no Moodle (4.1+) que possibilita a seleção e aplicação de diferentes famílias tipográficas para parágrafos e títulos.

TinyMCE Font Family Tipografia TinyMCE 6
GitHub Documentação
📂

moodle-tiny_fileimport

Plugin para o editor TinyMCE do Moodle que permite a importação ágil de arquivos e conteúdos via drag & drop e API integrada.

TinyMCE File Import Drag & Drop TinyMCE 6
GitHub Documentação
🚀

moodle-editor_tiptap

Plugin de editor WYSIWYG moderno para Moodle baseado na biblioteca TipTap, oferecendo uma experiência de edição extremamente rápida e limpa.

TipTap Editor WYSIWYG
GitHub Documentação
🛠️

moodle-tiny_toolbar

Plugin do TinyMCE que substitui a barra de ferramentas e os menus de todos os editores, com um construtor visual alimentado pelos botões registrados no editor.

TinyMCE Plugin TinyMCE Toolbar
GitHub Documentação
Formatos de Curso

📅 Formatos de Curso

Plugins de formatos de curso para enriquecer o layout pedagógico, a experiência do estudante e a navegação cronológica das salas de aula virtuais.

📅

moodle-format_timeline

Formato de curso em estilo linha do tempo social para o Moodle, organizando tópicos, semanas e atividades de forma cronológica, visual e engajadora.

Course Format Timeline Social UX
GitHub Documentação
Atividades Pedagógicas

🧩 Atividades Moodle

Módulos de atividades educacionais interativas integradas ao sistema de acompanhamento e conclusão de curso do Moodle.

🗺️

moodle-mod_imagemap

Módulo de atividade para criação de mapas de imagens interativos com hotspots clicáveis e suporte a exibição condicional baseada na conclusão de atividades.

Activity Mod Image Map Interactive
GitHub Documentação
📝

moodle-mod_offlinequiz

Fork da atividade Offline Quiz: provas de múltipla escolha do banco de questões, impressas e corrigidas no Moodle depois da digitalização das folhas de resposta.

Activity Module Fork Quiz
GitHub Documentação
Inscrição

🎟️ Métodos de Inscrição & Condições

Métodos de inscrição e o motor de condições que decide quem pode se autoinscrever num curso.

🎟️

moodle-enrol_conditional

Autoinscrição que depende das condições escolhidas: datas, campos de perfil, coortes, cursos concluídos ou listas de usernames, combinados com E/OU/NÃO. Pode suspender ou remover inscrições que deixam de cumpri-las.

Enrol Plugin Self enrolment Conditions
GitHub Documentação
🌳

moodle-local_enrolconditions

Motor de condições da autoinscrição condicional: subplugins enrolcond, árvore de condições com E/OU/NÃO e um hook para outros plugins acrescentarem condições.

Local Plugin Conditions Subplugins Hook
GitHub Documentação

Plugins do tipo admin tool para filtros avançados de participantes e modelos de certificado.

moodle-tool_participantscustomfilter

Plugin admin tool que adiciona suporte a filtros por campos personalizados de perfil na listagem de participantes dos cursos (/enrol/index.php).

Admin Tool Custom Filter Participants
GitHub Documentação
🎓

moodle-tool_certificate

Fork da ferramenta de certificados do Workplace: modelos de certificado no nível do sistema e das categorias de curso.

Admin Tool Fork Certificates
GitHub Documentação
