Ecossistema Open Source Moodle

Plugins, Ferramentas CLI & Extensões Moodle

Uma biblioteca completa de repositórios open source projetada para expandir o ecossistema Moodle: editores de texto WYSIWYG, módulos de atividades interativas, blocos visuais, formatos de curso, utilitários CLI de alta performance e projetos de infraestrutura.

Moodle Plugins

🔌 Plugins Moodle

Extensões, editores de texto, módulos de atividades, blocos interativos, formatos de curso, campos de perfil e ferramentas administrativas integradas ao ecossistema Moodle LMS.

Editores & Formatação

✍️ Editores & Formatação de Conteúdo

Plugins e utilitários de edição de texto para enriquecer a experiência de criação de conteúdos nas salas virtuais do Moodle, cobrindo os editores Atto, TinyMCE e TipTap.

📝

moodle-atto_justify

Plugin para o editor Atto nativo do Moodle que adiciona o botão de alinhamento de texto justificado na barra de ferramentas dos editores de cursos.

Atto Text Justify WYSIWYG
GitHub Documentação
✍️

moodle-tiny_justify

Plugin para o editor TinyMCE no Moodle (4.1+) que integra a opção de justificar blocos de texto diretamente na barra de ferramentas do TinyMCE.

TinyMCE Justify TinyMCE 6
GitHub Documentação
🔤

moodle-tiny_fontsize

Plugin para o editor TinyMCE no Moodle (4.1+) que permite selecionar e ajustar tamanhos de fonte customizados para trechos de texto formatado.

TinyMCE Font Size Tipografia TinyMCE 6
GitHub Documentação
🔠

moodle-tiny_fontfamily

Plugin para o editor TinyMCE no Moodle (4.1+) que possibilita a seleção e aplicação de diferentes famílias tipográficas para parágrafos e títulos.

TinyMCE Font Family Tipografia TinyMCE 6
GitHub Documentação
📂

moodle-tiny_fileimport

Plugin para o editor TinyMCE do Moodle que permite a importação ágil de arquivos e conteúdos via drag & drop e API integrada.

TinyMCE File Import Drag & Drop TinyMCE 6
GitHub Documentação
🚀

moodle-editor_tiptap

Plugin de editor WYSIWYG moderno para Moodle baseado na biblioteca TipTap, oferecendo uma experiência de edição extremamente rápida e limpa.

TipTap Editor WYSIWYG
GitHub Documentação
🛠️

moodle-local_tinytoolbar

Plugin local para configuração e personalização centralizada dos botões e disposição das ferramentas no editor TinyMCE do Moodle.

Local Plugin TinyMCE Toolbar
GitHub Documentação

moodle-format_timeline

Formato de curso em estilo linha do tempo social para o Moodle, organizando tópicos, semanas e atividades de forma cronológica, visual e engajadora.

Course Format Timeline Social UX
GitHub Documentação

moodle-mod_imagemap

Módulo de atividade para criação de mapas de imagens interativos com hotspots clicáveis e suporte a exibição condicional baseada na conclusão de atividades.

Activity Mod Image Map Interactive

Blocos & Banners

📢 Blocos Moodle

Plugins de blocos laterais e de conteúdo personalizáveis para destaque de avisos, recomendações e recursos nos cursos.

moodle-block_recommendation

Plugin de bloco para exibição de recomendações personalizadas em HTML, avisos estratégicos, banners e links de destaque em áreas do Moodle.

Block Recommendation HTML Banner
GitHub Documentação
Administração & Utilitários CLI

⚙️ Ferramentas de Administração & CLI

Plugins do tipo admin tool e scripts CLI para automatizar backups em lote, migração de banco de dados, filtros avançados de participantes e sinalizadores visuais de ambiente.

💾

moodle-tool_brcli

Ferramenta CLI (BrCLI) para backup e restauração em lote de categorias completas de cursos no Moodle diretamente via linha de comando.

Admin Tool CLI Backup & Restore
GitHub Documentação
👥

moodle-tool_bulkclienrolment

Utilitário de linha de comando para inscrição e matrícula em massa de usuários em cursos do Moodle com automação por script.

Admin Tool CLI Bulk Enrolment
GitHub Documentação
🗄️

moodle-tool_dbmigrate

Ferramenta CLI para migração eficiente e segura de banco de dados do Moodle entre diferentes SGBDs (como de MySQL para PostgreSQL).

Admin Tool CLI DB Migrate PostgreSQL
GitHub Documentação
🔍

moodle-tool_participantscustomfilter

Plugin admin tool que adiciona suporte a filtros por campos personalizados de perfil na listagem de participantes dos cursos (/enrol/index.php).

Admin Tool Custom Filter Participants
GitHub Documentação
🎗️

moodle-tool_ribbons

Plugin de administração para identificação visual de ambientes (Desenvolvimento, Homologação e Produção) com faixas coloridas configuráveis.

Admin Tool Ribbons DevOps
GitHub Documentação
